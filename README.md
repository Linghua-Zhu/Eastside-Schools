# 大西雅图学区对照 Greater Seattle School Compare

大西雅图 10 个学区（Seattle、Shoreline、Edmonds、Everett、Northshore、Lake Washington、Bellevue、Mercer Island、Issaquah、Renton）公立学校的全州排名、升学线和所在 zip 的房价，还有私校、托儿、课前课后托管、课外班、学费计算和报名日历。

网址：https://seattle-school-compare.github.io/

## 网站有什么

- **首页**：各学区的排名分布和房价，一张地图，这个月要做的事。
- **公校**：小学、初中、高中和选择校。每所学校一页，有全州排名、近五年趋势、升学线、附近的私校和相关日期。
- **比一比**：选两所小学，比它们对应的初中、高中和房价；也可以比两所同学段的学校。
- **私校**：48 所私校的地图、学费、入学考试、申请截止，以及课程和活动。
- **托儿**：0 到 5 岁。州政府持照托儿中心的地图和名单，各学区的公立学前班，说中文的托儿，怎么选。
- **课外**：各学区小学的课前课后托管（选一所小学看谁来办、时间、价格和报名），以及按类别整理的课外兴趣班。
- **花多少钱**：公校私校混着上，最多 4 个孩子，算 K 到 12 年级一共要付多少学费。
- **日历**：幼儿园报名、天才班、选择校、转学和私校申请的日期。

## 数据来源

| 内容 | 来源 |
|---|---|
| 州考成绩和全州排名 | OSPI 在 data.wa.gov 公开的州考成绩（9fjj-2374，CC BY-ND 4.0）。排名按 SchoolDigger 的算法自己算 |
| GreatSchools 评分 | GreatSchools |
| 房价 | Redfin 近期成交，每个 zip 取 4 房成交价中位数，样本见 `data/` |
| 升学线、选择校、日期 | 各学区官网 |
| 私校学费、入学和课程活动 | 各校官网 |
| 学校位置 | NCES 学校地址库，个别学校按官网地址补 |
| 持照托儿和学龄托管 | DCYF 在 data.wa.gov 公开的持照名单（was8-3ni8） |
| 课前课后托管、公立学前班、说中文的托儿 | 各学区、机构和州政府官网 |

算法和每项数据的细节见网站的“关于和数据说明”页。数据整理到 2026 年 10 月。
